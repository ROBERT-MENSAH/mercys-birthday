# Mercy — A Story Worth Celebrating

A personalized, interactive digital birthday and life-story experience celebrating Mercy.

## Tech Stack
- Semantic HTML5
- Modern Vanilla CSS3 (Custom Properties, Flexbox, Grid, Dynamic Viewport Units)
- Vanilla ES6+ JavaScript (Modular, Accessible, Event-Driven)
- Canvas Confetti for celebratory milestone rendering

## Project Directory Structure
```
MERCY'S BIRTHDAY/
├── assets/
│   ├── images/     # Curated personal photographs
│   ├── videos/     # Authentic video moments
│   └── audio/      # Audio assets and background tracks
├── css/
│   ├── variables.css   # Color palette tokens, typography, elevation & spacing
│   ├── base.css        # Modern CSS reset, base typography & layout primitives
│   ├── components.css  # Buttons, cards, story badges, modal/lightbox, player
│   ├── sections.css    # Chapter narrative sections, story timeline, birthday reveal
│   └── responsive.css  # Mobile-first adaptive media queries
├── js/
│   ├── data.js         # Centralized verified asset & story registry
│   ├── audio.js        # Web Audio / Autoplay policy handling
│   ├── lightbox.js     # Accessible media modal with keyboard & touch support
│   ├── animations.js   # Intersection Observer-based scroll reveals
│   └── main.js         # Core application initialization & Easter Egg logic
└── index.html          # Semantic document entry point
```
